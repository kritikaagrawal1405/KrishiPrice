# KrishiPrice Phase 2: Run Instructions

This document provides the necessary instructions to reproduce the Phase 2 Forecasting Engine experiments.

## 1. Environment Setup & Dependencies

Ensure you have a Python environment (e.g., Python 3.10+) with the following dependencies installed. You can install them via pip:

```bash
pip install pandas numpy scikit-learn statsmodels xgboost tensorflow matplotlib joblib
```

## 2. Dataset Location

Phase 2 requires the processed dataset generated by Phase 1.
The expected input file is located at:
`data/processed/selected_series.csv`

## 3. Configuration

All hyperparameters, horizon selections, target columns, split ratios, and features are centralized in the configuration file:
`src/utils/config.py`

Modify this file to test new features or different horizons without touching the pipeline code.

## 4. Official Command to Run Phase 2

The official execution entry point for Phase 2 is:
```bash
python src/run_phase2.py
```
*Note: `src/run_pipeline.py` is the Phase 1 script (processing data and initial feature engineering preview) and should NOT be used for forecasting.*

## 5. Expected Outputs

Upon running the official script, the following outputs will be generated:

1. **Metrics:**
   - Saved in: `results/metrics/model_comparison.csv`
   - Contains a comprehensive comparison of all models (Naive, MA, ARIMA, XGBoost, LSTM, GRU) across primary and secondary series.

2. **Plots & Visualizations:**
   - Saved in: `results/plots/`
   - Includes history, chronological train/val/test splits, predictions vs. actuals, and residuals.

3. **Model Artifacts & Scalers:**
   - Saved in: `models/`
   - Trained models (.keras for DL, .pkl for XGBoost/ARIMA)

4. **Predictions:**
   - Saved in: `results/predictions/`
   - CSV files containing raw predicted vs actual arrays for analysis.

## 6. How to Reproduce

1. Verify `data/processed/selected_series.csv` exists.
2. Run `python src/run_phase2.py`.
3. Check `results/metrics/model_comparison.csv` for the final scores.
4. Check `results/plots/` for visual analysis of the model performance.
